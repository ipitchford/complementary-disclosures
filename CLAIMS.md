# Claim map and exclusions

Anonymous · v2.0.0-candidate · 14 October 2026

These statements describe the revised candidate's mathematical scope. Universal support is the manuscript proof; finite replay only checks the listed instances.

| Claim | Hypotheses and conclusion | Evidence / boundary |
|---|---|---|
| CD-01: clearing and loss bound | Positive outside liabilities imply contraction and unique clearing. A componentwise asset reduction of total size sigma from a fully solvent baseline gives outside-creditor loss between zero and sigma. | Written argument using classical clearing and conservation; not a new general loss-conservation principle. |
| CD-02: layered magnitude | For m switches, beta>0 and source outside debt b0>0, c=(1+beta)^(1-m); loss is sigma-c(1-product(2t_j-1))/2. Every proper switch submenu has minimax width c; full disclosure has zero width. | Explicit family, not all financial networks. The ratio is c/(1+b0); approaching one as order grows requires parameters to change. |
| CD-03: prior transition | Under independent switch priors, proper-submenu expected full-fibre width is c product(kappa_j). Submodularity holds exactly when product over k outside {i,j} of kappa_k times (1-kappa_i-kappa_j) is nonnegative for every pair. | Zero factors cannot be cancelled. For m>=2, either some kappa is zero or every pair sum is at most one. 775 finite parameter vectors checked. Not Bayesian posterior-support width. |
| CD-04: quantiles and objective divergence | For 1<=n<m uniform-prior switch reports, normalized width is a product of n independent uniforms, hence its quantile is given by a Gamma(n,1) transform. Explicit independent network modules give different minimax and expected-width optimal menus. | n=0 is deterministic full initial width. Symmetric optima need not be unique. Quantile exceedance is not probability of an incorrect answer. |
| CD-05: one-layer affine mechanism | Doubly stochastic source-to-sink liabilities permit loss b_s+t_0. Reporting all other simplex coordinates identifies it; any proper submenu retains width one. | Reviewer-suggested construction. It depends on excluding a direct t_0 report; one interbank layer is not a statement that only one bank layer defaults. |
| CD-06: affine menu characterization | On a simplex with affine loss c.t and report matrix A, minimax width is min_lambda osc(c-A^T lambda); under errors eta it is min_lambda [osc(c-A^T lambda)+2 eta.|lambda|]. | Standard LP strong-duality specialization. Exact identification iff c is in span of the all-ones vector and rows of A. 70 rational certificates check finite cases, not the universal theorem. |
| CD-07: heterogeneous noise | Set delta_j=min(4 eta_j,2), D=max delta_j. The product gap is 1-product(1-delta_j) for D<=1 and D for D>=1. Full-menu layered width is c/2 times this gap; proper menus retain c. | All eta_j>=0, m>=1; branches agree at D=1. 155 finite configurations checked. The small-error expression must not be extrapolated into the coarse-error regime. |
| CD-08: finite computational study | All 44 inputs retained: 29 width-complete, 14 unresolved, one zero-shock. The 1,878 queries contain 657 exact rational witnesses, 1,207 UNSAT and 14 UNKNOWN results. | Strict normal/optimized retained replay passed. Historical summary counts are not newly witness-verified evidence. UNSAT remains solver-dependent; execution completion does not remove unresolved cases. |
